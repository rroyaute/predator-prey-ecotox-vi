# Workflow with Julia scripts
## Description of the scripts
Checks are included in all of the scripts to test the functions along the way. Just un-comment and run to see the results printed on the terminal.

- `dose_response.jl`: contains the dose-response functions, populations generation with varying NECs and $x_0$, and simulations of the effect of a varying dose on the populations mean characteristics and deviations. Stores the results as a `CSV` file for each population (one with positive covariance between $x_0$ and NEC, one with negative covariance, and one with no covariance).
- `method_jacob.jl`: contains the functions to compute and classify the stability of the prey-predator system with given parameters.
- `parallel_stab.jl`: uses the functions from `method_jacob.jl` to compute the stability grid of stability regime in the $(d^2, \sigma^2)$ plane. Uses parallel computing for improved efficiency. The results are stored in a `CSV` file.
- `plot_dose_response.jl`: Creates and saves the plots of dose-response relationship: some distributions (histograms / scatter), the evolution of the mean and dispersion for varying dose, and the corresponding trajectories on the stability grid background.
- `plot_stab.jl`: Creates and saves the plot of the stability grid (reproduction of Figure 3 from xxx et al. (yyyy) with mathematically strict convergence regimes)

## Workflow to reproduce the stability grid background (needed first)
As this figure is used as the background for one of the plots in the next part, this needs to be done first.

To run a script, simply execute (in the `Julia` folder):
```bash
cd Julia # To go to the `Julia` folder; do not run this line if you're already in it
julia script_julia.jl # Replace "script_julia" by the name of the script
```

`parallel_stab.jl` needs to run to compute the stability grid values, followed by `plot_stab.jl` to create and save the stability grid plot.

Alternatively, use the Makefile commands (in root):
```bash
make command_name
```

The command names are "compute_stability" to create the CSV files, and "plot_stability" to create the plot.

## Workflow to create the dose-response data/figures
`dose_response.jl` creates the summary values: the dose and the corresponding mean characteristic and standard deviation. They are stored in a CSV file. `plot_dose_response.jl` contains functions to plot some distribution of the populations, the plot of mean and std plots vs the dose and the stability background plot with trajectory for varying dose.
__Careful:__ at the moment, running `plot_dose_response.jl` only creates this last plot. You'd have to change it to also re-create the figures called `Dose-response_mean_std.pdf`, `hist_plot_distrib_x_NEC.pdf`, `scatter_plot_distrib_x_NEC.pdf`, and `summary_plot_dose_response.pdf`.

Alternatively, use the Makefiles command: "compute_dose_response" to create the CSV files, and "plot_dose_response" to create the stability background plot with trajectory for varying dose.

## Note on Make
If you want to plot something but don't have the CSV files, the magic of Make happens: it will automatically run the compute command before. For example: you remove all the files for the background stability plot. `make plot_stability` will run firstly `parallel_stab.jl` then only `plot_stab.jl`.

To remove all intermediate files for the stability plot, use `make clean_stability`.

To remove the dose-response CSV files, use `make clean_dose_response`.

To remove all CSV files, use `make clean`.

__To run the full workflow, use `make`__

# Data description
The outputs of the `julia` scripts are in `outputs/data/`.
- `fig_3_data_julia.csv`: array of numbers in {1, 2, 3, 4} that each correspond to a different stability regime. The shape should be (len(d), len(sigma)).
- `fig_3_d_vals.csv`: list of values for d in the previous data.
- `fig_3_sigma_vals.csv`: list of values for sigma in the previous data.
- `dose-response_*.csv`: dataframes with 4 columns. "_neg", "_null", or "_pos" correspond to the sign (or absence) of correlation in the distribution of $x_0$ and NEC among the population. The columns of the dataframes are:
    - "Dose": the concentration
    - "yhat_mean": the mean among the population of the characteristic with given concentration
    - "yhat_std": the standard deviation among the population of the characteristic with given concentration
    - "d": the value of d corresponding to the given concentration
